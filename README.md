# 🛒 Amazon Website Clone

A front-end clone of the Amazon homepage built using HTML and CSS. This project replicates the look and feel of the original Amazon UI, including the navigation bar, product sections, and footer layout.

## 🔥 Features

- Clean and responsive homepage layout
- Navigation bar with search functionality
- Product sections showcasing different categories
- Styled hover effects and interactions
- Footer with multiple informational links
- Built with only HTML and CSS (no frameworks)

## 🧰 Technologies Used

- HTML
- CSS
- Font Awesome (for icons)
